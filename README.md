# إنسترجع — موقع استرجاع حسابات إنستغرام المعطّلة

**الحالة:** نشط
**أُضيف:** 2026-09-25
**المسار:** `projects/instagram-recovery`

موقع عربي متجاوب (أندرويد وآيفون) مع صفحات خدمة ومدونة مهيأة لمحركات البحث.

## التشغيل محلياً

```bash
# من projects/instagram-recovery
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

انسخ `.env.example` إلى `.env.local` وعدّل رابط الموقع والبريد قبل النشر حتى تعمل روابط Sitemap وOpen Graph بشكل صحيح.

## SEO

- عناوين ووصف لكل صفحة
- `sitemap.xml` و `robots.txt`
- بيانات Schema.org للمؤسسة والمقالات
- مقالات في `lib/articles.ts` مبنية على كلمات بحث شائعة مثل: استرجاع حساب انستقرام معطل، من الجوال، حقوق النشر، بدون كلمة سر

لإضافة مقال جديد: أضف عنصراً في مصفوفة `articles` داخل `lib/articles.ts` (العنوان، الوصف، الكلمات المفتاحية، الأقسام).

## الأمان

النموذج لا يطلب كلمة مرور إنستغرام. الطلبات تُحفظ محلياً في `data/requests.json` أثناء التطوير. على الاستضافة اربط النموذج ببريدك أو واتساب للأعمال.

الموقع غير تابع لميتا/إنستغرام، ويساعد مالك الحساب على الاستئناف الرسمي فقط.
